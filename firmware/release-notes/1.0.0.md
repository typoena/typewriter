Typoena 1.0 is live. Everything a writing machine needs is in place: Vim-style
editing on e-paper, notes kept as Markdown on the SD card, a command palette for
files and settings, focus sessions, Typo keeping you company in the side panel,
and :gs / :gl to push and pull your notes through your own git repository.
Updates arrive over Wi-Fi, and the device now checks at boot and tells you when a
new one is out. 1.0 is the same build as 0.15.0 under its first stable number.
Run :update to install it.
